## 🚀 Overview
This repository contains a **static event portal** designed for **Microsoft Learn Student Ambassadors (MLSA)**.  
It includes pages for registration, schedule, gallery, and contact information.

The portal can be used as a template for student events, hackathons, workshops, or community gatherings.

---

## 📂 Pages & Features
- **Home (`index.html`)** → Landing page for the portal.  
- **Register (`register.html`)** → Event registration form.  
- **Schedule (`schedule.html`)** → Agenda, sessions, and timings.  
- **Gallery (`gallery.html`)** → Showcase of past events/media.  
- **Contact (`contact.html`)** → Contact details for queries.
